# Store submissions

Everything needed to put Fastmail Assist on the Chrome Web Store and on Firefox Add-ons (AMO), kept next to the code so that it stays true.

| File | What it is |
| --- | --- |
| [`../PRIVACY.md`](../PRIVACY.md) | The privacy policy. Its public URL, for both stores: `https://github.com/jarofclay/fastmail-assist/blob/main/PRIVACY.md` |
| [`chrome-web-store.md`](chrome-web-store.md) | Every field of the Chrome Web Store listing and of its Privacy practices tab, ready to paste |
| [`firefox-amo.md`](firefox-amo.md) | Every field of the AMO listing, the notes to the reviewer, and the source-code submission |
| [`screenshots/`](screenshots/) | Store screenshots at 1280×800 and the Chrome small promo tile at 440×280, generated by `scripts/store-assets.mjs` |

## What to upload

From the GitHub release of the version being submitted (https://github.com/jarofclay/fastmail-assist/releases):

- Chrome Web Store: `fastmail-assist-chrome-<version>.zip`, as it is.
- Firefox Add-ons: `fastmail-assist-firefox-<version>.zip`, plus `fastmail-assist-source-<version>.zip` as the source code (AMO requires it because the build is bundled).

Both zips have `manifest.json` at the top level, which is what the stores expect.

## Regenerating the screenshots

They are composed from the browser test's screenshots, so they show the extension's own UI and nothing pretending to be Fastmail:

```sh
FA_SHOTS=/tmp/fa-shots xvfb-run -a npm run e2e     # on macOS: without xvfb-run
node scripts/store-assets.mjs /tmp/fa-shots         # writes store/screenshots/
```

## Order of work

1. Finish milestone M1 in DESIGN.md (the extension has to have run against a real account).
2. Submit to both stores as **unlisted** first (Chrome: visibility Unlisted; AMO: "On your own" or listed but hidden), install from the stores, use it for a while.
3. Then switch to public.

## Account notes

- Chrome Web Store needs a Google account for the developer console and a one-time registration fee. A dedicated account used only for publishing keeps this separate from everything else.
- AMO needs a Firefox account. No fee.
- Both stores require a contact email on the listing; use one you are happy to see published.
